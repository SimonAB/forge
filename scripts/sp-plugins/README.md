# Super Productivity plugins (Forge helpers)

Helpers that run **inside** Super Productivity via the Plugin API. Local REST
cannot create projects (`POST /projects` → 404); `PluginAPI.addProject` can.
See [docs/superproductivity.md](../../docs/superproductivity.md).

## forge-bulk-projects (one-shot)

Creates SP projects for Forge board folders that are missing an exact title match.

```sh
# From Forge home — rebuilds plugin.js from the live board vs SP list
python3 scripts/sp-plugins/build_forge_bulk_projects.py
```

Then in Super Productivity: **Settings → Plugins → Upload Plugin** → choose
`forge-bulk-projects.zip` → enable. A snack reports how many projects were
created. The plugin records completion in its synced data and will not recreate
on later loads.

Afterward, map titles to ids in `config.yaml` (`superproductivity.project_ids`).

| File | Role |
|------|------|
| `forge-bulk-projects/manifest.json` | Plugin manifest (`addProject` permission; `icon.svg`) |
| `forge-bulk-projects/icon.svg` | Vector anvil mark (`currentColor`; SP sanitises SVG and rejects `<image>` embeds) |
| `forge-bulk-projects/icon.png` | Same mark as PNG |
| `forge-bulk-projects/plugin.js` | Generated by the build script |
| `forge-bulk-projects.zip` | Upload this |
| `build_forge_bulk_projects.py` | Rebuild zip from current board |

## Finder → SP project folders

Permanent adapter (not a plugin):

```sh
python3 scripts/forge-sp-menu-tree.py --forge-home . --dry-run
python3 scripts/forge-sp-menu-tree.py --forge-home .
# or: forge superproductivity mirror-menu-tree [--dry-run]
```

## Focus one SP project (Open TASKS)

Used by Forge.app when **Open TASKS** targets Super Productivity:

```sh
/tmp/sp-cdp-venv/bin/python scripts/forge-sp-focus-project.py '<sp-project-id>'
```

See [docs/superproductivity.md](../../docs/superproductivity.md). The old path
`scripts/sp-plugins/apply_finder_menu_tree.py` forwards to the menu-tree script.

## Full-backup JSON (avoid unless intentional)

`forge-sp-projects-import.json` (if present) is a **full SP state** snapshot with
extra projects spliced in. Importing it **replaces** all Super Productivity data.
Prefer the bulk plugin. Do not treat Desktop copies of that file as routine tooling.
